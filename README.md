# 酒馆角色卡收集、审计与分类工具

本仓库用于在本地工作副本上收集、扫描、去重、分类和整理 SillyTavern 角色卡。项目采用“先生成可审计结果，再由人工批准写入操作”的流程；原始网盘收藏不是自动化脚本的整理目标。

## 安全边界

- 原始收藏只作为人工筛选来源；收集脚本只复制，不移动、不删除或改写来源文件。
- 扫描、重复检测和分类阶段生成报告，不直接修改角色卡。
- 模型阶段会把裁剪后的角色卡字段发送到所配置的外部服务，必须得到明确授权后才能运行。
- 整理阶段先生成计划；只有人工检查并批准同一批次后才允许执行。
- 默认整理操作是复制。第六阶段虽支持 `move`，但移动必须单独批准，且不应作用于原始收藏。
- 同名不等于重复；同名但内容不同的文件按不同版本保留。

## 快速开始

先确认工作树和测试基线：

```powershell
git status --short
node --test
```

这些测试使用临时目录和本地模拟服务，不会处理真实收藏或调用外部模型。实际扫描、分类和整理命令请从 [运行手册](./docs/runbook.md) 复制，并先阅读对应的副作用与警告。

## 主要目录

```text
角色卡分类/
├─ data/                   # 本地工作数据；不纳入 Git
├─ reports/                # 批次报告与执行日志；不纳入 Git
├─ src/                    # 各阶段脚本与共享模块
├─ test/                   # 自动化测试
├─ docs/                   # 当前文档、运行手册和历史快照
├─ 分类标准.md             # 唯一权威分类规则；代码依赖此路径
├─ CONTEXT.md              # 领域词汇表
└─ AGENTS.md               # 长期维护规则
```

`SillyInnkeeper-main/` 仅用于格式兼容研究，不是运行依赖，也不属于本项目的修改范围。
