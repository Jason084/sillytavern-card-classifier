# 分类政策

[English](./classification-policy.md)

根目录 [`分类标准.md`](../分类标准.md) 是唯一权威且可执行的分类政策。[英文译文](./classification-standard.en.md)仅供阅读，并必须记录对应中文源文件的 SHA-256。

050、051 和 052 读取中文政策。复核阶段从“第一优先级”和“第二优先级”标题解析允许类别。每个模型批次都会记录政策 SHA-256；源文件任何字节变化后，原批次都会拒绝续跑。

修改政策时：

1. 可执行规则只编辑 `分类标准.md`。
2. 区分排版修改与语义修改；两者都会改变哈希，语义修改还必须创建新模型批次。
3. 同步英文阅读译文及其源文件哈希标记。
4. 运行 `npm run check:policy` 和完整测试。
5. 不得改写已有批次，使其看起来使用了新政策。

架构与运行手册不会复制类别列表，以免产生第二份规则正文。
