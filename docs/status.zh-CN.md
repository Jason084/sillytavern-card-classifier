# 项目状态

[English](./status.md)

最后核实日期：2026-09-14。

`0.1.0` 仍是首个公开预览基线。当前 `main` 分支包含 010–110 阶段、34 项基于合成数据的单元与集成测试、服务商中立的模型配置、与批准绑定的整理及标签计划、完整双语文档，以及覆盖 Node.js 22/24 的 Windows CI。

第 110 阶段已实现并完成验证。它从已批准且完整执行的第 100 阶段计划推导标签，保留已有标签，追加一级分类与适用的最终同人 IP，并把与哈希绑定的新副本写入空目标目录。生成的标签计划必须另行批准才能执行；需要原样复制的兼容例外必须在预览命令中逐个显式指定。

维护者已在不公开私人角色卡和批次文件的实际数据上验证：计划输出 15,134 张，实际写出 15,134 张；其中 15,133 张新增标签，1 张经显式批准作为兼容例外原样复制，共新增 17,150 个标签。公开仓库中的实现证据是合成测试；全新克隆无法复现这些实际数据汇总数字。

公开仓库不包含角色卡、生成的运行报告、私人收藏路径或私人批次历史。全新克隆中没有权威数据批次；使用者必须生成自己的工作副本与报告。

支持平台为 Windows 10 或更高版本、PowerShell 7、Node.js 22 或 24 LTS。Linux 与 macOS 可能可以运行部分 Node 阶段，但不属于 v0.1 支持契约。

已知限制：

- 模型分类质量取决于所选端点，必须人工复核。
- 内置中文分类政策服务于特定工作流，使用前应自行审核。
- 060 为可丢弃工作副本保留显式 `move` 选项；后续整理阶段只允许复制。
- v0.1 不承诺兼容公开前创建的私人批次。
- 第 110 阶段支持现有解析器可识别的 PNG `tEXt` 元数据和 JSON 角色卡；异常元数据必须修复，或经显式批准作为原样复制兼容例外。
